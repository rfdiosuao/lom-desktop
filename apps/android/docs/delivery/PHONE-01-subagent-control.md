# PHONE-01：配对桌面的手机子代理管理

历史实现说明。本轮交付真实定义管理与新委派准入，不宣称完整的运行任务启停验收。

## 已实现

- 经现有配对验签、加密 RPC 暴露 `subagent.list/save/toggle/delete`，返回手机真实定义、模型组和全局委派开关。
- 所有变更在原生配置锁内检查 revision、内置定义限制、名字冲突、数量/文本上限和实时模型组。未暴露的原生推理配置保留。
- `enabled` 持久化到原有配置/数据库映射；旧配置默认启用。原生设置页的旧编辑草稿不能覆盖桌面刚改的开关。
- 禁用的定义不进入新工具名单、提示名单、新委派或恢复；关闭手机全局委派时卡片恢复和排队恢复也拒绝。
- 禁用队首不会让其后的可运行任务永久等待；拒绝或启动失败显示失败状态并继续队列。
- 远端变更只有持久化成功才确认。Room 写入/镜像提交失败返回错误，不能以只更新内存冒充保存成功。部分写入结果需要重新读取核对。

## 行为验证

在 JDK 17 / Android SDK 36，执行：

```sh
./gradlew :app:testLomDebugUnitTest \
  --tests '*LomRemoteSubagentsTest' \
  --tests '*SubAgentDefinitionTest' \
  --tests '*SubAgentAdmissionQueueTest' \
  --tests '*SubAgentPersistenceRoundTripTest' \
  --tests '*BackupSubAgentsTest' --max-workers=2 --console=plain
```

38 项通过：定义17、远端编辑4、真实内存队列3、持久化映射往返4、备份10。初次缺少本地 rclone.aar，补用现有开发依赖；另一次编译跨越新增源文件时失败，最终完整增量编译及上述测试通过。未修改或提交二进制依赖。

## 未执行与边界

- 未连接真实手机、未安装 APK、未验收桌面到手机的真实加密往返、杀进程重启恢复。
- 未注入真实磁盘满、SharedPreferences 提交失败或 Room 故障；持久化失败处理有源码复核，不能称为故障实测。
- 禁用只阻止新委派及恢复，不会停止正在运行的任务。全局委派开关仍由手机设置控制。
- 运行任务列表、即时启动/取消与执行结果回传仍未由本契约覆盖，此处仅保留实现边界说明。
- 旧手机不支持新 RPC 时，桌面须显示未支持，不能退回本地草稿假成功。
- 没有服务器改动、核心改动、合并、发布或部署。
