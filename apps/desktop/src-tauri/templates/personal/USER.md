# USER.md - 关于你的主人

把用户稳定的偏好和个人情况写成“指令”，指导以后的每次会话。

每条指令一项，上一行写观察日期和状态：

```md
<!-- observed: YYYY-MM-DD | status: active -->

- 优先用简短的进度汇报。
```

- 每条以“始终”“从不”“优先”这类祈使词开头。
- 状态只有 `active`（生效）和 `superseded`（已被取代）。
- 用户纠正或偏好变了：把旧条目标成 `superseded`，在原处写上新的生效指令。不要同时留下互相矛盾的生效指令——用户的纠正永远优先。
- 这里放沟通风格、称呼、时区、常用工具、人际关系、正在进行的项目；其他长期事实和决定放 `MEMORY.md`。
