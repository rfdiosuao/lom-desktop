# Personal Agent mascots

Six image assets generated with the built-in image generation tool on 2026-10-23 for Lom, using the six-concept board approved by the user in this project conversation. Each mascot was separately recreated as an alpha PNG. No third-party mascot or character pack was imported.

| File | Display name | Use |
|---|---|---|
| deer-01.png | 绒绒小麓 | optional |
| deer-02.png | 薄荷小麓 | optional |
| deer-03.png | 叶影小麓 | optional |
| deer-04.png | 琉璃小麓 | optional |
| deer-05.png | 暖绒小麓 | optional |
| deer-06.png | 团子小麓 | default |

The generated PNGs retain their original alpha. Runtime presentation uses contain sizing without a circular clipping mask. These character assets replace Personal Agent avatar instances, not the application wordmark or the signed-in user's profile picture.

All six PNGs were downscaled to 256×256 (alpha kept) on 2026-10-23: the largest on-screen size is 64 px, so 256 px covers 2×+ displays while cutting the assets from about 7.5 MB to about 0.4 MB.
