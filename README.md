<h1 align="center">麓鸣 Lom</h1>
<p align="center">把想法交给 AI，让电脑与手机协同完成工作。</p>

<p align="center">
  <a href="https://lom.entermodetwo.com">官网</a> ·

</p>

Lom 是一个连接电脑、手机与 AI Agent 的工作空间。通过自然对话发起任务，让不同 Agent 分工协作，在同一处查看进展与结果。

本仓库开源桌面外壳和基础界面组件；Release 提供官方完整版安装包。两者范围不同，详见[开源说明](docs/SCOPE.md)。

<p align="center"><sub>让 AI 从回答问题，走向完成工作。</sub></p>
