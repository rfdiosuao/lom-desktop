# 开源范围与发行包

本仓库以独立初始历史发布，采用逐文件选取的方式提取 Lom 的桌面基础组件，并增加可独立运行的本地文档入口。

## 公开源码

包含桌面窗口、界面设计令牌、图标、基础控件、Markdown 渲染、本地文件工作台、测试和独立构建配置。

不包含 AI 执行引擎、账号与计费服务、服务端实现及接口配置、手机连接与配对协议、跨设备加密与调度、部署脚本、运行数据和原仓库历史。没有指向私有仓库的子模块或自动下载私有核心的构建步骤。

源码许可证沿用所提取桌面代码的 **AGPL-3.0-only** 声明，见 [LICENSE](../LICENSE)。项目名称和 Logo 用于标识 Lom，不表示对第三方衍生产品的官方认可。依赖各自的许可证见 [第三方说明](THIRD_PARTY.md)。

## 官方完整版安装包

Release 中名称以 `Lom-0.1.4-` 开头的安装包是官方完整版的分发副本，包含运行所需的非公开核心程序与服务接入。它们不是本仓库公开源码的可复现构建结果，不应据此认为完整产品源码已经开源。公开源码许可证不自动覆盖这些安装包内的所有独立组件；第三方组件仍遵循其自身许可证。

Release 自动生成的 **Source code (zip/tar.gz)** 仅包含这里的桌面外壳源码。每次发行均提供安装包的 SHA-256 校验文件。

截至首次发行，Mac 包使用临时签名，Windows 包未使用商业代码签名。Windows 安装若缺少 WebView2，可能需要联网获取运行时。安装包与公开源码的功能范围、构建来源与验证记录分别说明，不混用版本号。
