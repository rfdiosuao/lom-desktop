# 开源范围与发行包

本仓库使用独立历史，逐文件提取可公开的桌面代码，不导入原仓库历史、私有子模块或用户数据。源码许可证为 **AGPL-3.0-only**，见 [LICENSE](../LICENSE)。第三方许可见 [来源说明](THIRD_PARTY.md)；名称与 Logo 不表示对衍生产品的官方认可。

## 这次实际开放了什么

| 领域 | 公开实现 | 限制 |
| --- | --- | --- |
| 原生窗口 / 文件 | Tauri 窗口、系统对话框选择的本地文本/图片读取、限量读取、导出 | 不允许前端任意读路径；文档不自动保存 |
| 基础桌面界面 | 设计令牌、图标、Markdown、按钮、导航、分段、标签页、开关、状态、列表/设置/页面布局、圆形头像外圈动效 | 调用方提供数据，不依赖私有账号状态 |
| Skillhub 入口 | 双层上传菜单、搜索/路径区分、键盘、边界、空/错误态、旧草稿追加/替换选择 | 只有交互组件和回调；真实发现、Lom 任务、云端上传/审核仍由官方适配 |
| 本机 CLI 接入 | 可选本地运行时启动/健康检查/退出清理、回环地址校验、认证请求/超时、事件重连、CLI 发现/创建/显式发送/取消 | 不含执行引擎；需要用户自行安装兼容运行时及 CLI。预览页只读取真实列表，不自动发消息/执行命令 |
| 开发与协作 | 独立文档工作台、组件预览、测试、构建、公开内容扫描、社区完整待办与 PR/Issue 入口 | 完整生产聊天、权限及工作区仍待逐模块提取 |

这些实现均为可编译的公开源码，不是将整个产品目录复制后删除密钥。`src/desktop` 的组件已移除私有状态和业务调用，使用显式回调；`src/runtime` 只含本机桌面接口，不含手机/云端业务契约。界面回调必须继续核验数据作用域和真实结果，不得用示例数据充当接入成功。

## 继续私有

手机端及其连接/配对/跨设备协议、服务端及其部署/接口配置、商业模型执行内核、账号登录与订阅计费实现、线上渠道、管理后台、商业密钥、用户会话/运行记录均不公开。

没有私有核心的自动下载、链接或构建步骤。默认不设置 `LOM_CORE_BIN` 即可使用文档工作台。只有显式设置该环境变量，才尝试在独立应用数据目录启动用户提供的本机运行时。启动令牌只在内存及子进程环境中；事件连接令牌仅用于本机协议，不可记录完整 URL。

[社区计划](../COMMUNITY_PLAN.md) 为需求的公开脱敏视图。包含手机/IM/服务端待办仅为解释产品方向；这些实现不因此变为开源。未修、待核验与历史已修严格分开。

## 官方完整版与源码构建不同

Release 中的官方 Mac/Windows 完整安装包包含非公开运行时和服务能力。它们不是本仓库公开源码的全部可复现构建，公开源码许可不自动覆盖其中所有独立组件。每个 Release 的版本、安装包和 SHA-256 以该发行记录为准；源码工作台版本单独维护。

GitHub 自动生成的 Source code zip/tar.gz 只包含此公开仓库。不能根据官网完整版的功能截图，认定克隆本仓库即可获得手机控制、商业模型或完整聊天流程。安装签名与更新行为也以具体发行说明为准。
